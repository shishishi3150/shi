## 3. 共用传感通信与I2

AUV距离–方位传感器：最大6 m，距离噪声标准差0.2 m、方位噪声3°：

\[
P_D(d)=1-0.9(d/6)^2\ (0\le d\le6),\qquad P_D(d)=0\ (d>6).
\]

不模拟虚警、声学遮挡，启用未支持项明确拒绝。量测通过Jacobian转为位置及协方差，共用局部Kalman滤波跟踪[x,y,vx,vy]。发送端滤波、包内容、发送机会和损伤机制共用；各方法发送**观测时刻本地track**，不单独给予某方法更新时刻状态。

默认延迟3步=0.45 s、丢包10%；loss_rate与target_loss_range必须一致。它是独立消息抽象，不是完整声学信道。AoI=now−t_obs，传输延迟=t_recv−t_send，分别记录。按source/measurement ID去重，丢弃同源乱序旧观测。

Base（hold）按(t_obs,confidence,−source_id)选择最新原始观测时刻track，12 s过期；接收端不外推或多源融合。Traditional_CV只对最新源常速度外推。I2对所有有效源外推：

\[
F(\Delta)=\begin{bmatrix}I&\Delta I\\0&I\end{bmatrix},\quad
x_i^-=Fx_i,\quad P_i^-=FP_iF^T+Q(\Delta),
\]
\[
Q(\Delta)=0.35^2\begin{bmatrix}
\Delta^4I/4&\Delta^3I/2\\
\Delta^3I/2&\Delta^2I
\end{bmatrix}.
\]

年龄和confidence调节协方差，使用保守covariance intersection：

\[
q_i=\operatorname{clip}(confidence_i,10^{-3},1)e^{-AoI_i/12},\quad
C_i=P_i^-/\max(q_i,10^{-6})+10^{-9}I,
\]
\[
w_i=\frac{1/\operatorname{tr}C_i}{\sum_j1/\operatorname{tr}C_j},\quad
P_f^{-1}=\sum_iw_iC_i^{-1},\quad
x_f=P_f\sum_iw_iC_i^{-1}x_i^-.
\]

单源同样调整协方差。融合标量t_obs取最新贡献源，不代表全部融合信息同样新鲜；各源ID、时间、权重另记。I2不改变噪声、消息大小、频率、延迟或丢包，不读取目标真值。

## 4. I1：有限候选预测安全筛选

名义动作限幅后，用同一艇体动力学预测20步=3 s，每步五子步，随后接入有界纵向/偏航反馈制动预测。备用段达到二维速度≤0.02 m/s且偏航角速度≤0.02 rad/s即提前停止，最长200步=30 s；未在上限内达到停止条件的候选不标为安全。安全裕度0.15 m、不确定性附加裕度0.1 m。仅使用公开边界/浅水轮廓、本艇及合法目标/伙伴信息，其他艇按常速度传播，不由真值补未知对象。

备用段上限不是每次固定预测33 s：本模型USV直航0.4 m/s制动约4.05 s，AUV直航0.5 m/s约1.95 s；USV大横荡/偏航的边界状态制动明显更慢，27个纵荡/横荡/偏航组合实测最长29.25 s。因此同时检查动作预测段和直到接近静止的备用段，而非只判断短窗口内是否接触。近似静止是数值终端条件，不能当作已证明的不变集。

接收端不能由静止或横荡速度推断艇艏方向，因此伙伴/目标使用**艇长为直径的外接圆包络**；自身保留真实胶囊与旋转。检查积分扫掠区间，并计入位移、转角和障碍运动界；所有有界输入明显远离时可用同一预测假设下的保守可达管快速判定。

名义动作不可行时枚举3×3力/力矩网格，另加保留名义偏航的零推力/负推力制动候选及当前反馈制动候选；所有候选预测均受纵向速度下限0约束，不能倒车，按归一化动作距离排序，返回首个全段满足裕度且备用制动达到停止条件的可行者。全不可行时选已检查候选中最大小间隙者，记录infeasible/fallback。slack=max(0,margin−predicted_min)只表示几何裕度缺口；停止条件未达标时即使slack为0，也仍可infeasible。额外记录terminal_recoverable、backup_time_s。

这是带备用制动可行性检查的有限候选预测过滤，**不是已证明CBF/QP最优投影或严格前向不变保证**。未知障碍、常速度障碍外推、离散候选、数值终端条件均限制结论；预测忽略不可见波浪扰动，全不可行时仍没有保证安全的退路。

预测内核使用Numba编译，不启用fast-math，保留模型参数、每步五子步及环境步边界float32位置舍入；独立测试与原对象动力学/扫掠胶囊计算对照。Numba首次编译和进程启动开销应与稳定运行耗时区分。旧轻量策略中缺少备用段字段的配置仍按其记录的旧预测参数运行，不静默改变历史模型评估。

执行 nominal→safe→限幅/active mask→executed，Replay存完整executed动作。目标Actor使用无梯度真实筛选。Actor训练用

\[
a_{ST}=a_{nom}+\operatorname{stopgrad}
(\operatorname{project}(a_{nom})-a_{nom}).
\]

Q前向用真实筛选结果，反向采用**近似identity straight-through导数**，不宣称离散筛选可微。I3只做reject_only，拒绝而不修复历史动作。

Actor更新先投影公共参考动作一次，再针对每个价值头只重算发生变化的接收艇；其他接收艇的筛选只依赖其本艇输入和已收到的信息，不依赖本次候选中其他艇的动作，因而可复用。该复用有损失、梯度和优化器更新对照测试。分别记录i1_target_solver_time_s与i1_actor_solver_time_s，避免把Actor投影隐藏在未归因耗时中。

## 5. 红船、shadow与同状态审计

训练回合中红船使用第1节描述的APF、局部切向绕行与3-DOF动力学向保护区推进。USV排斥与绕行响应改变其速度和航向；红船不会仅因回合用时而放弃。AUV不向红船施加碰撞、拖曳或抓停力；围捕是水平投影上的有效几何包围。

默认 `task.post_capture_end_step=650`。首次满足原围捕门槛时锁存 `capture_success`、`first_capture_step` 和时间，仅触发一次 `capture_confirmed`，红船立即锁存WITHDRAW，目标沿用入口西侧(6,30)。撤退参考偏航上限仍为0.4×0.675=0.27 rad/s，物理与控制器不改。此时done=False、bootstrap=1，不重置状态、不清空历史、不追加规则接管：训练仍使用在线探索/学习动作，Actor回放仍使用所选Actor，规则回放仍使用原规则。五艇的传感、通信、I1和真实执行动作入Replay均继续。每步仍计算实际围捕门，失围会降低AUV保持质量收益，但不抹掉首次围捕记录、不重复发首次围捕奖。

红船整个胶囊越过入口线x=11 m且向外速度<-0.02 m/s时锁存 `withdrawal_cleared_entry`；该指标只诊断，不提前结束，也不成为成功硬门。累计650步以success真实终止，bootstrap=0；碰撞、触礁、越界、突破及实际场景事故仍可优先提前终止，回合success=False，但保留此前capture记录。旧配置缺少此字段或显式为0时保持首次围捕立即终止，`--show-withdrawal` 仅为这种历史配置追加原独立规则演示；当前配置不会再追加第二段或切换蓝方控制器。撤退仍是围捕确认触发的场景约定，不声称红船自主判断USV压力或全程严格围住。

首次围捕前，shadow从reset与实际红船同时出发，同模型同波场但无USV影响；不同路径会采样波场的不同位置。长期shadow差距可能混入先前路径扰动，因此增加同当前状态干预。围捕触发撤退时冻结并隐藏入侵shadow、清除旧audit，后续停止阻截审计，长期gap/progress诊断归零。当前v2正奖励在撤退阶段停止入侵阻截、Shapley与阻截几何信用，三项权重转为持续接近和AUV支持收益；避免把脚本撤退误算成USV阻截贡献。reward.phase_contract=positive_motion_capture_support_v2进入奖励hash，用于隔离旧奖励曲线。历史cost_v2配置仍保留原成本处理。

每10步复制**当前红船状态、导航记忆、动力学**，相同波浪episode和绝对时间，预测20步=3 s。蓝方以当前executed控制开环保持，经真实动力学积分。比较all、none、without_0、without_1：

\[
P_S=d(start,goal)-d(end_S,goal),\quad
E=P_{none}-P_{all},\quad m_i=P_{without_i}-P_{all},
\]
\[
\phi_0=\tfrac12[(P_{none}-P_{without_1})+m_0],\qquad
\phi_1=\tfrac12[(P_{none}-P_{without_0})+m_1].
\]

分支接触或导航恢复使audit无效。远场可证明零作用时effect=0、分支progress为null，不伪造推进值。有效证据要求audit有效、年龄≤20步、E≥0.01 m。cooperation_supported还要求两艇removal effect均≥0.01 m。全部USV审计只用于辅助奖励和诊断，**不作为AUV围捕成功的硬门槛**；成功不能自动解释为两艘USV均有贡献。

这是短时开环干预近似，不是严格因果识别或完整闭环未来。额外模拟步与墙钟时间单列。实际红船事故分 natural_navigation_failure / blue_influenced_navigation_failure / attribution_unresolved，shadow故障单列。route_available只在reset做静态通航，不证明含动态艇、转弯半径、饱和的完备可达性。

## 6. 成功与终止语义

任务目标字段为 `task.objective=auv_encirclement`。以下全部连续保持20步=3 s即确认首次围捕成功（当前配置继续运行到累计650步）：

1. 三艘AUV均active，每艘中心距红船2–5 m。
2. 按真实AUV相对红船的方位排序，最大圆周空隙≤160°。
3. 红船严格位于三AUV实际位置构成的凸包内部，到每条边的有符号距离最小值≥0.25 m，排除共线、擦边及单侧聚集。
4. 三艘AUV本地track年龄均≤1 s、误差均≤3 m。
5. reset静态路线存在；无接触、突破或数值/场景故障。

几何判据不指定任何顶点、朝向或三角阵型；旋转、平移及艇编号排列均不影响判定。USV接近、阻滞差距、反事实效果、两艇信息质量及红船推力占比写入 `support_gates`，用于辅助诊断。红船被蓝艇有效迫停不会因推力下降而否定AUV围捕。仅USV堵住目标、仅AUV探测跟踪或两艘AUV接近均不能成功。

红船中心扫掠路径进入保护区半径4 m即突破；接触和突破先于围捕成功。135 s未围捕为timeout失败，守到时限本身不算成功。期限是**有限任务终止terminated、bootstrap=0**。外部采样器cut是truncated、bootstrap=1，next取真实最后端点，不跨reset拼接。非法数值动作/状态明确失败，numerical_error终止不吞掉任意Python异常。旧策略若缺少当前围捕目标字段，明确拒绝按新任务评估，保留历史文件。

## 7. 无槽位正奖励（当前 cooperative_positive_v2）

生产入口为 `usv_env/reward.py`，参数来自 `configs/scene_template.yaml` 的 `reward.positive`。重新逐项核对护航附件后，在v1基础上迁移速度匹配和航向引导：AUV接近自由围捕距离带并随移动目标保持围捕，USV学习保护区方向的阻截几何与实际作用。附件属于参考材料，不改变用户的当前约束。13个实验共享同一奖励，不按I1开关加分；观测、物理、成功条件和MATD3基础设置保持原值，不提供指定槽位或三角顶点。

正常步骤每艇过程收益为 `r_process = 0.02 * g_safety * g_motion * sum(w_k*q_k)`。各质量在 `[0,1]`，同角色权重非负且总和为1，故每艇过程收益在 `[0,0.02]`；inactive艇为0。没有时间扣分，也不因单纯存活另发常数奖励。

| AUV过程项 | 权重 |
| --- | ---: |
| 本艇距红船2–5 m距离带的质量 | 0.20 |
| 团队距离质量（平均/最差各一半） | 0.15 |
| 团队距离质量 × 最大方位空隙质量 | 0.15 |
| 团队距离质量 × 实际凸包边距质量 | 0.15 |
| 本艇距离质量 × 合法本地跟踪质量 | 0.10 |
| 连续保持进度 | 0.10 |
| 围捕运动速度质量 | 0.10 |
| 围捕运动航向质量 | 0.05 |

| USV过程项 | 权重 |
| --- | ---: |
| 接近红船2–4 m交战距离带 | 0.25 |
| 新且有效的同状态总阻截效果 × 准备度 | 0.25 |
| 接近质量 × AUV围捕准备度 | 0.20 |
| 新且有效的个体正Shapley贡献 × 准备度 | 0.15 |
| 接近质量 × 保护区方向的阻截几何质量 | 0.15 |

距离质量为 `q=1/(1+violation/8m)`，不指定方位或位置。方位和凸包收益乘团队距离质量，减少远距离形式包围的收益。跟踪质量仍使用合法本地估计、年龄、误差和方差，成功跟踪门槛不放宽。USV阻截使用有效且年龄≤20步、总效果≥0.01 m的同状态审计；无证据、证据过期、个体贡献≤0时对应收益为0，不用中性0.5发奖。总效果经 `tanh(E/0.1m)`，个体正贡献经 `clip(phi/0.1m,0,1)`；二者的准备度系数为 `0.25+0.75*usv_readiness`。围捕确认后，入侵阻截、个体贡献与阻截几何三项权重转入 `usv_withdrawal_reward`，按持续接近 × AUV准备度赚取，不把红船脚本撤退记为阻截贡献。

AUV运动引导只使用距离带和目标速度。令 `d=||p_red-p_i||`、`n=(p_red-p_i)/d`、`e=d-clip(d,2,5)`，构造 `v_ref=clip_speed(v_red+0.20*tanh(e/4m)*n,0.5m/s)`。带外引导闭合距离，过近引导退开，带内匹配红船世界速度；没有指定角度、顶点或旋转相位。速度质量为 `1/(1+(||v_i-v_ref||/0.25m/s)^2)`，航向质量为 `(1+cos(psi_i-angle(v_ref)))/2 * min(1,||v_ref||/0.05m/s)`；参考速度为0时航向项为0。速度和航向质量均乘本艇距离质量，避免远处运动奖励形成固定收益底座。直接到最近距离带的线段若穿过岛礁膨胀区，运动质量乘0；净距0至0.5 m线性恢复，避免直接穿礁的速度奖励。膨胀量为原浅水buffer加AUV外接半艇长，不生成绕行航点或接管动作。一般距离/包围收益保留，引导绕行仍依靠环境和策略。

USV阻截几何使用红船至保护区的单位方向 `a` 和 `offset=p_usv-p_red`，质量为 `clip((offset·a)/||offset||,0,1)/(1+(lateral/4m)^2)`，再乘接近质量。它只表示位于目标前方、靠近推进走廊的形势，不冒充因果贡献。USV不照搬护航的领航速度匹配，防止奖励它跟在入侵红船后面。没有单独支付正距离差，避免往返反复领取“进步奖”。

安全门为 `g_safety=clip(最小艇体净距/1m,0,1)^2`。动作门为 `(1-0.05*归一化执行命令平方均值)*(1-0.05*超阈偏航比例)`，仅调低过程收益，不单独为低动作或低偏航发奖。净距来自现有艇体、边界与岛礁计算，I1动作预测和真实碰撞判定不变。

首次围捕确认当步每艘active艇一次性 `+2`；后续650步任务后段继续按任务质量记奖。安全完成终局每艘active艇 `+2`。碰撞、触礁、越界、突破、超时、场景异常或数值故障的失败终止当步，所有过程项、首次围捕项与终局项均为0，失败优先于同一步围捕。已有异常检测与终止处理保留；不把任意Python异常改写为正常终局。

2026-11-07按用户要求，安全完成终局奖从20降为2；首次围捕+2、过程每艇每步0至0.02及所有失败当步0均不变。最长900步，每艘始终active艇的失败未折扣回报仍至多 `899*0.02+2=19.98`；成功局宽界为 `900*0.02+2+2=22`，累计650步安全完成时上界为17。终局2分不再大于所有失败局的累计收益上界，原成功支配校验已取消；正值、权重和episode_budget预算校验保留。共同历史之后，立即失败仍不能通过少扣未来时间成本提高回报。

公共 `gamma=0.99`、n-step7保持不变。当前终局2分不提供成功局回报高于所有失败局的保证，也不保证Full优于所有消融或训练收敛。`train.csv`同时保留原始和折扣回报、成功率、安全事故、首次围捕与回合长度；best依次比较成功率、较低碰撞/触礁/越界率、首次围捕率和折扣回报。保留原始曲线，不强制上升、不跨奖励或源码版本混图。

真正terminated仍禁止bootstrap；外部collector cut保留真实端点并允许bootstrap；reset状态不用于回报补算。失败不追加吸收伪轨迹、剩余时长尾款或追溯扣回历史收益。旧 `cooperative_positive_v1`、`cooperative_cost_v2` 和 `cooperative_pbrs_v1` 分支保留原公式供历史配置使用；模板中的旧cost/potential付费参数不作为当前正奖励系数。

本轮迁移设计、行为反例和学习验证见[护航向围捕奖励迁移报告](../validation/reward_design_20261107/REPORT.md)。原v1正奖励与耗时/存储调查为历史证据。规则轨迹证明奖励行为和场景可达，短测证明当前默认设置能更新，均不能代替长期多种子学习验收。

## 8. I3：完整历史联合动作与已观测结果

只从当前在线训练进程resident Replay检索，不加载演示库、测试轨迹或未来成功标签。每候选为某真实执行时刻完整[5,2]动作；五个value head共享同候选，不拼不同历史艇动作。

Replay current state/context/nominal/executed取n-step首条；next state/obs/context/phase取真实窗口末条。n-step已实现回报折扣累加，终止刷新pending，外部cut只提交已有段。历史动作匹配其首条current context；query是目标端点s_(t+n)，不混用当前batch或reset状态。

后段WITHDRAW复用原两位phase编码3，原SEARCH/ENCIRCLE/HOLD为0/1/2；成功终态也为3但bootstrap为0。这样无需改变Replay容量、打包或网络输入维度，I3不会把撤退阶段的候选当成围捕前同阶段候选。Actor观测及网络架构保持原样。

默认K8、search_pool512、max_distance2、minimum_quality0.2、λ0.5、advantage_clip1、uncertainty_scale1、temperature1、return_scale1。必须有元数据、phase一致、信息valid mask一致、active mask一致。距离为物理尺度标准化与分组加权RMS：目标至保护区20 m、艇相对目标/艇间10 m、速度0.5 m/s、艇艏sin/cos、礁间隙、AoI3 s、log variance/log13、安全裕度0.3 m。尺度预先声明，不用held-out数据拟合，也不是原始真值直接无权欧氏距离。

瞬时质量代理：

\[
q_{instant}=\operatorname{clip}\{0.35mean(valid)+
0.35(1-G/(2\pi))_++0.3causal\_evidence,0,1\}.
\]

同时使用**已经观测到的n-step结果**。active均值折扣回报及置信：

\[
R_h=\frac{\sum_i active_i\,r_{h,i}^{(n)}}{\max(\sum_i active_i,1)},\quad
o_h=\sigma(\operatorname{clip}(R_h/return\_scale,-60,60)),\quad
q_h=q_{instant,h}o_h.
\]

按q_h≥0.2过滤。正回报增置信、负回报降置信、零回报o_h=0.5。已提交窗口发生collision、reef_collision、out_of_bounds、scenario_anomaly、numerical_error时，该窗口所有首动作均排除，所有I3变体遵守。pending未提交窗口不可检索。这里是已实现有限n-step回报，**不是已知整回合未来结果或最终成功标签**。

用query合法信息预测器筛掉当前不安全候选，保留历史动作原样。双目标Critic取min：

\[
Q_\pi=\min(Q'_1(s_{t+n},a_\pi),Q'_2(s_{t+n},a_\pi)),\quad
Q_h=\min(Q'_1(s_{t+n},a_h),Q'_2(s_{t+n},a_h)),
\]
\[
A_h=\operatorname{clip}(Q_h-Q_\pi,0,1),\quad
c_h=\frac{e^{-d_h^2/T^2}q_h}{1+u_h/uncertainty\_scale}.
\]

u_h为五头平均绝对twin分歧。选择active头平均λc_hA_h最大的**一个完整候选**，然后

\[
y_i=r_i^{(n)}+\gamma^nb[Q_{\pi,i}+0.5c_hA_{h,i}].
\]

无可靠候选、无正优势或terminal b0时增强严格零，回退原MATD3。Replay采样与I3检索独立RNG，检索不改变公共采样序列。

| 变体 | 相对Full变化 |
| --- | --- |
| Random_History | 保留phase/info/activity/outcome过滤，随机候选，无距离阈值/相似度置信因子 |
| No_State_Matching | 保留phase/info/activity/outcome过滤，按质量排名，无距离阈值/相似度置信因子 |
| No_Safety_Screening | 跳过query当前安全筛选，其余过滤不变 |
| Hard_Max | 保留匹配与安全/结果过滤，去掉置信、λ及正优势上限，直接用正历史优势 |

所有变体均twin min、完整联合动作。记录候选数、phase匹配、距离、安全拒绝、选中质量、i3_realized_nstep_return、i3_outcome_confidence、twin Q、优势、置信和实际target增量。部署Actor不检索Replay/中央历史，轻量模型不带候选库。
